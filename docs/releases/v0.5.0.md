A fix release for *The Legend of Zelda: Ocarina of Time* for Nintendo Switch 2 (game version 1.1.1): the fog and
lighting are back to the game's own. **No game files are included**: the setup builds the game on your PC from your own
dump.

## Install or update

- **Already have 0.4.0:** start the launcher; it offers 0.5.0 and updates. The first start after the update prepares
  the shaders again (about a minute and a half on the boot screen).
- **New install:** download **`NX2navi-Setup-0.5.0.exe`** below, put it next to your `.nup` dump of the game and start
  it. Windows SmartScreen warns on the first start because the setup is not signed: choose *More info* and *Run
  anyway*. The launcher builds the game (10 to 25 minutes, once), prepares every shader and starts it.

**Requirements:** Windows 10 or 11; an x86-64 CPU with SSE4.2; 16 GB of RAM; about 30 GB free for the game and 1.5 GB
for the launcher; a GPU with Vulkan 1.3, `VK_EXT_external_memory_host` and `VK_EXT_mesh_shader` (current NVIDIA and AMD
cards).

## Fixed in this release

- Kokiri Forest and other foggy areas are no longer washed out in a bright white and yellow haze: the fog the game
  builds up on the GPU adds up correctly again (0.4.0 broke the shader loop that adds to it).
- Small white flowers and other foliage in the grass no longer flicker white from frame to frame.
- The trees stay fixed: no dark columns reaching the sky.

## Known issues

- Entering a new area can hold one frame for about 0.2 s while its textures are set up, and the first visit to an
  area after an install can pause briefly while the graphics driver builds what it has not seen.
- A rare crash in the game's particle code.
- DLSS Frame Generation is not offered yet: AMD FSR 3.1 frame generation works on every GPU, NVIDIA's included.

Report problems as issues, with the game's log (`logs\nx2navi.log` in the game folder) and what you were doing.
